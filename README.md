# Skilled E-learning Landing Page

A responsive e-learning landing page developed as part of my Full Stack Development training.

This project focuses on creating a modern, visually appealing, and responsive user interface using HTML5, Sass (SCSS), JavaScript, and Vite.

## Technologies Used

- HTML5
- Sass (SCSS)
- JavaScript
- Vite
- Responsive Web Design
- Git and GitHub

## Project Features

- Responsive layout for desktop, tablet, and mobile devices
- Modern e-learning landing page design
- Reusable Sass components and organized stylesheets
- Responsive images and visual elements
- Optimized production build using Vite

## Project Structure

- `index.html` — Main HTML document
- `sass/` — Sass stylesheets and partials
- `img/` — Images and visual assets
- `main.js` — JavaScript entry point
- `package.json` — Project dependencies and scripts

## Running the Project Locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Generate the production build:

```bash
npm run build
```
